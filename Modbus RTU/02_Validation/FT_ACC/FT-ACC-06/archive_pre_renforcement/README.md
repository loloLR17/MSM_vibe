# Archive pré-renforcement — FT-ACC-06

Cette archive conserve l'ancien package FT-ACC-06 avant reconstruction selon GEL-GOV-02 et FT-STR-06 gelée.

Elle contient l'ancienne source, les 23 génériques et les anciens cas instanciés fondés notamment sur :
- lectures hors plage redondantes avec FT-STR-06 ;
- franchissements de frontières logiques considérés à tort comme invalides en lecture ;
- scénarios `multi_bloc` utilisant parfois des quantités dépassant les limites Modbus ;
- cas artificiels non représentatifs de l'adressage réel.

Cette archive est historique uniquement et ne doit pas être exécutée comme référentiel V1 actif.
