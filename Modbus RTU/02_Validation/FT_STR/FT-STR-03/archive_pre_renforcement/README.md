# Archive FT-STR-03

Ce répertoire conserve les artefacts historiques antérieurs à la reconstruction FT-STR-03.

Les anciennes fiches instanciées utilisaient notamment une méthode fondée sur la comparaison de la plausibilité MSW/LSW, et mélangeaient encodage, répétabilité et cohérence temporelle. Elles sont conservées uniquement pour traçabilité.

Elles ne doivent jamais être utilisées pour une validation active.
