# Archive FT-STR-06

Ce répertoire conserve les artefacts historiques antérieurs à la reconstruction FT-STR-06.

`instancie_legacy/` contient l'ancien lot champ-par-champ (183 fiches plus index et overview). Il est conservé pour traçabilité uniquement et ne doit plus être utilisé comme validation active.

Les anciennes fiches mélangeaient accessibilité, contrôles de géométrie déjà couverts par FT-STR-01/02 et hypothèses pré-GEL-MAP-V1, notamment autour de l'adresse 4017.
