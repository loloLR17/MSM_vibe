# Archive pré-renforcement FT-STR-05

Ce répertoire conserve les artefacts historiques antérieurs à la reconstruction FT-STR-05.

`instancie_legacy/` contient l'ancien index, l'ancien overview et les anciennes fiches par zone, inchangés. Ils peuvent contenir des noms ou doctrines pré-GEL-MAP-V1, notamment le doublon historique à l'adresse 4017.

Ces fichiers sont **historiques uniquement** et ne doivent jamais être utilisés pour générer, exécuter ou conclure la validation active.
