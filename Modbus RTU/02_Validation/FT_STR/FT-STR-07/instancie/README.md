# Instanciation active FT-STR-07

Cette instanciation applique la doctrine reconstruite de FT-STR-07 à GEL-MAP-V1 sans réintroduire les anciens tests « 20 snapshots identiques » sur des blocs dynamiques.

- `COUVERTURE_FT-STR-07_GEL-MAP-V1.csv` décrit les catégories de cibles et les axes de preuve.
- `RESULTAT_FT-STR-07_GEL-MAP-V1.md` sépare ce qui est démontrable documentairement de ce qui exige une exécution sur cible.
- `validate_ft_str_07_structure.py` contrôle uniquement la structure mécanique de la suite et les catégories présentes dans GEL-MAP-V1.

Les anciens tests détaillés et instanciés sont conservés sous `archive_pre_renforcement/` et sont inactifs.
