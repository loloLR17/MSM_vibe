# Archive pré-renforcement FT-STR-07

Ce répertoire conserve les artefacts historiques antérieurs à la reconstruction de FT-STR-07.

- `detaille_legacy/` contient les 12 anciens tests détaillés génériques ;
- `instancie_legacy/` contient l’ancien index, l’ancien overview et les 27 anciens tests instanciés.

Ces fichiers sont conservés intacts pour traçabilité. Ils peuvent contenir l’ancienne doctrine « 20 lectures/snapshots identiques », y compris sur des données dynamiques, ainsi qu’un ancien pseudo-snapshot complet du Bloc 4 incompatible avec la limite FC03 de 125 registres.

Ils sont **historiques uniquement** et ne doivent jamais être utilisés pour générer, exécuter ou conclure la validation active.
